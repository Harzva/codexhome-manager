# Code of Conduct

## Our standard

Be respectful, specific, and constructive. Discuss behavior and technical evidence rather than personal characteristics. Harassment, threats, discrimination, doxxing, and publication of another person's credentials or private data are not acceptable.

## Scope

This standard applies to repository issues, pull requests, discussions, review comments, and project-related public spaces.

## Reporting

For ordinary conduct concerns, contact the repository owner through their GitHub profile without publishing private details. Security vulnerabilities must use GitHub's private vulnerability reporting flow described in [SECURITY.md](SECURITY.md).

Project maintainers may edit or remove inappropriate content and restrict participation when necessary to keep the community safe.
