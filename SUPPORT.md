# Support

CodexHome Manager is an early-alpha community project.

- Reproducible bugs: use the GitHub bug report template.
- Feature proposals: use the feature request template.
- Security vulnerabilities: use private vulnerability reporting, never a public issue.
- General setup failures: review [docs/troubleshooting.md](docs/troubleshooting.md) before filing an issue.

Reports should include the `codexhome --version` output, operating system, minimal reproduction, and redacted diagnostics. Do not attach credentials, raw sessions, or a complete real registry.
